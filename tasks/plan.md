# План: убрать оплату и тарифы из форка (#3)

Файл живет только в ветке `feature/3-remove-billing` и удаляется перед мержем. Задачи ведутся в GitHub Issues дочерними к #3: #11–#27, зависимости проставлены через «blocked by».

## Решения

- Первой идет подзадача «полный доступ»: одна точка дает всем полный тариф, функции работают сразу. Остальные подзадачи удаляют то, что она обходит.
- Клиенты (desktop, web, админка) перестают вызывать эндпоинты оплаты раньше, чем бэкенд их удаляет. Так каждая подзадача оставляет приложение рабочим.
- Каталог тарифов и `utils/subscription.py` удаляются последними: на них опираются все проверки.
- Тариф в учете использования заменяется константой, учет остается.
- Модули удаляются вместе со своими тестами, удаленные тесты перечисляются в коммите.

## Можно параллельно

- После #11: #12, #13, #15–#18 трогают разные места бэкенда. #14, #22, #23, #24 не зависят от бэкенда.
- #15 и #19 обе правят `routers/listen/runtime.py` и `routers/sync.py`, их лучше делать по очереди.

## Риски

| Риск | Влияние | Что делаем |
|---|---|---|
| Модули, читающие тариф из Firestore напрямую, продолжат видеть `basic` | Высокое: часть функций останется закрытой | В #11 они перечислены явно, тест проверяет пользователя без подписки |
| Канал `billing:openExternal` удалится вместе с окном оплаты | Высокое: перестанут открываться ссылки календаря и онбординга | В #21 канал сначала переносится в `externalUrl.ts` |
| `PlanType` используется как метка в учете | Среднее: сломаются импорты | В #26 метка заменяется константой до удаления каталога |
| #25 и #26 не укладываются в один заход | Среднее | В issues записано, как их делить |
| Удаленные тесты маскируют поломку оставшегося поведения | Среднее | Удаляем только тесты удаляемых модулей, остальные правим |
| `desktop/macos` ломается на удаленных эндпоинтах | Низкое: приложение только для справки | Не трогаем, это записано в #3 |
